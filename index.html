?常见问题

        
先看这里，大部分“连不上”都是请求方式或 Key 的问题。

      

    


    

      OCS 5.2.3 弹“检测到题库配置中包含可疑代码 / 拼接属性访问”
      
这是 OCS 启发式扫描的误报。旧版生成器把错误提示写成 return ['...' + msg, undefined]，被规则当成 obj['a' + 'b'] 这种“拼接属性访问”。它其实是数组字面量，不是隐藏属性调用。更新后的配置改成先 const message = ...，再 return [message, undefined]，不会命中该规则。重新复制一次配置并保存即可；只有确认来源可信时才点“我了解风险，仍然使用”。

    

    

      配置成功，但提示“域名/ip 不在脚本的白名单中”
      
这是 OCS 5.2.3 的域名白名单检查，不是配置错误。在 OCS 脚本最上面的 // ==UserScript== 和 // ==/UserScript== 之间加一行 // @connect api.deepseek.com，保存并刷新网课页面即可。即使请求方式选的是 fetch，5.2.3 也可能做这个检查，所以两种模式都建议加。

    

    

      OCS 列表显示“连接失败（401）”，但测试页能答？
      
OCS 5.2.3 的列表状态是用 HEAD 探测题库地址，而且不带 Authorization 请求头。DeepSeek 的接口要求鉴权，所以这种探测必然返回 401；OCS 把 401 标成“连接失败”，但实际答题的 POST 请求会带上 Key。不要在没验证前就认定 Key 失效：以“测试 DeepSeek”或 OCS 实际搜题结果为准；实际搜题也返回 401 才是 Key 的问题。

    

    

      OCS 提示“题库连接失败 / Failed to fetch”
      
先确认 Key 已填、余额充足。若测试页能通但 OCS 不通，通常是课程页 CSP 拦截了 fetch：把“请求方式”改成 GM_xmlhttpRequest 重新复制配置，并在 OCS 脚本头部加 // @connect api.deepseek.com（或在脚本管理器里把 @connect 设为宽松模式）。

    

    

      返回 401 / Authentication Fails
      
Key 不正确或已被删除。注意 Bearer  后面要有一个空格；重新复制 Key，不要带多余引号或换行。

    

    

      返回 402 / Insufficient Balance
      
DeepSeek 账户余额不足，去平台充值。也可以换一个有余量的 Key。

    

    

      返回 429 / Rate limit
      
请求太频繁。把 OCS 搜题并发降到 1，等几十秒再试。

    

    

      DeepSeek 返回空内容 / 不是有效 JSON
      
JSON 模式偶尔会返回空内容，重新搜一次即可。仍失败可把 temperature 调到 0，或取消“发送 thinking: disabled”再试。

    

    

      答案看起来对，但 OCS 不点选项
      
先确认题型识别正确（单选/多选/判断/填空）。单选应返回一个字母，多选用 # 连接，判断返回“正确/错误”，填空多个空也用 # 连接。如果 OCS 版本较旧，建议升级到当前版本。

    

    

      提示“当前题库配置暂不支持图片、公式等题目处理”
      
这是旧配置没有引用图片字段导致的提示。更新后的配置在 messages.handler 里读取 env.images、env.suggestion_title 和 env.suggestion_options，OCS 5.2.3 会识别为支持图片题，并把图片按顺序作为 image_url 发给 deepseek-flash。重新复制一次题库配置即可；同时确认 OCS 高级设置里开启了“图片题优化”，模型不要选不支持视觉的 deepseek-v4-pro。

    

    

      图片题 / 公式题能用吗？
      
可以。OCS 5.2.3 开启“图片题优化”后，会把题目/选项里的图片转成 base64 放进 env.images；新版配置会把图片按顺序作为 image_url 内容发给 deepseek-flash，公式图、截图题也能识别。注意：deepseek-v4-pro 不支持视觉输入；图片过大或过多可能超过接口限制。生成器里的文本框测试只能测文字，图片题请在 OCS 实际页面验证。

    

    

      AI 答案一定对吗？
      
不一定。模型可能理解错题意或出现幻觉。建议只用来对答案、复习和自测；涉及成绩提交时先人工核对，并遵守课程平台和学校的规定。
